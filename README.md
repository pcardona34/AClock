# AClock
Analog Clock for a GNUstep Desktop

## Why another fork

Because the new one from nu-gap has an [issue](https://github.com/nu-gap/apps-aclock/issues/1).

## Where it came from

In the meanwhile, I created this repo from the subversion release, i.e.:

```console
svn co svn://svn.savannah.nongnu.org/gap/trunk/user-apps/AClock
```

## How to install

1. Run [agnostep-apps-manager](../../../agnostep-apps-manager).
2. Select category: *gnustep-recommended-apps*
3. Select application: *Aclock*
4. Read Info.
5. Confirm installation.
